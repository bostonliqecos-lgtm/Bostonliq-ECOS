# ECO BOSTONLIQ

Экологическая платформа Бостанлыкского района. Node.js ≥ 22.5, **без внешних npm-зависимостей** (встроенный `node:sqlite`).

## Запуск
```
export APP_SECRET=$(openssl rand -hex 32)      # обязательно, секрет подписи сессий
export ADMIN_EMAIL=you@example.uz ADMIN_PASSWORD='длинный-пароль'   # первый администратор
npm start        # http://localhost:3000
npm test         # 20+ проверок прав, баллов, идемпотентности
```
Переменные: `PORT`, `DB_FILE`, `REPORT_REWARD` (EcoBall за принятое обращение, по умолчанию 10), `BASE_URL`.

## Что реализовано
Роли и права (таблицы roles/permissions/role_permissions, проверка на сервере), регистрация, вход (scrypt), восстановление пароля, обращения с картой, координатами и фото, история статусов, модерация, мероприятия с записью и лимитом мест, кошелёк EcoBall (атомарные транзакции, `idempotency_key`, баланс не может уйти в минус), cashback у партнёров с одноразовыми QR-кодами, новости, поиск, обратная связь, FAQ, политика и соглашение, журнал аудита, панель управления, PWA, ru/uz/en (меню), тёмная тема, доступность (skip-link, aria, focus).

## Что нужно подключить самостоятельно
1. **Почта** для восстановления пароля: сейчас ссылка пишется в лог сервера (`[RESET LINK]`). Подключите SMTP/Resend в обработчике `/api/reset/request`.
2. **HTTPS** (nginx/Caddy перед сервером) и резервное копирование `data.db` и `uploads/`.
3. **Push-уведомления в фоне** требуют VAPID-ключей и сервиса отправки; сейчас реализованы согласие и внутренние уведомления.
4. **Юридические тексты**: страницы privacy/terms — шаблоны, их нужно проверить юристом.
5. **Координаты территорий** (Чарвак, Чимган, Бельдерсай) приблизительные — поправьте в таблице `territories`.
6. Если нужен PostgreSQL/Supabase и RLS: схема в `schema.sql` переносится почти без изменений; сейчас права обеспечиваются сервером, прямого доступа к БД у клиента нет.
Секретов в клиентском коде нет. Подключений к платёжным системам нет: EcoBall — внутренние баллы, не деньги.
